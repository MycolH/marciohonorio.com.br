# Marcio Honório Sociedade de Advogados

**Domínio:** [marciohonorio.com.br](https://marcihonorio.com.br)

Este repositório tem como objetivo o desenvolvimento do site institucional da **Marcio Honório Sociedade de Advogados**, voltado para a divulgação de informações sobre a empresa, suas áreas de atuação e conteúdos jurídicos relevantes.

---

## 📌 Objetivo

 Criar uma plataforma digital moderna e acessível que:
 - Apresente informações institucionais da sociedade de advogados.
 - Divulgue serviços e áreas de especialização.
 - Compartilhe notícias e artigos jurídicos.
 - Facilite o contato com clientes e interessados.

---

## 🛠️ Tecnologias
 
 O projeto poderá utilizar:
 
 - HTML
 - CSS
 - JS
